# Phase A2 — Interactions + evidence

Status: **implemented.** Extends the `assessment` app with quizzes, attempts,
server-side grading and evidence capture. Mounted at `/api/assessment/`.

Out of scope (delivered later): mastery computation, adaptive selection,
flashcards, UI.

Companion docs: `docs/assessment/A1.md` (content models + teacher API),
`docs/assessment/00_recon.md`.

---

## 1. Models (`backend/assessment/models.py`)

| Model | Fields |
|---|---|
| `Quiz` | `author` FK → `users.Teacher`, `kind` (DIAGNOSTIC/TOPIC_PRACTICE/CHAPTER_TEST/MOCK_EXAM), `title`, scope: `subject` Char / `chapter` FK `planner.Chapter` / `topic` FK `planner.Topic`, `config` JSON, `is_active`, timestamps |
| `QuizAttempt` | `student` FK, `quiz` FK, `started_at` (auto), `submitted_at`, `status` (IN_PROGRESS/SUBMITTED/EXPIRED), `seed`, `question_ids` JSON (ordered uuids), `score` |
| `AttemptAnswer` | `attempt` FK, `question` FK, `response` JSON, `is_correct`, `partial_score` 0..1, `time_spent_s`, `hint_used`, `misconception` FK (null), `answered_at`; unique `(attempt, question)` |
| `Evidence` | `student` FK, `topic` FK, `source` (QUIZ/FLASHCARD/PLANNER_EXERCISE/TEACHER_GRADE), `source_ref_type`, `source_ref_id`, `score` Decimal 0..1, `difficulty` 1–5, `occurred_at`, `question` FK (null), `weight_modifier` (default 1.0); index `(student, topic, occurred_at)` |

`Quiz.config` is normalised by `normalize_quiz_config()` to
`{"num_questions": int, "time_limit": int|None, "difficulty_range": [lo, hi]}`;
`time_limit` is minutes. `Evidence` is idempotent via
`unique (source, source_ref_type, source_ref_id, question)`.

## 2. Grading engine (`backend/assessment/engine/grading.py`)

Pure Python (no Django, no DB, no clock). Same structure as `planner/engine/`.

* **Response format** (stored verbatim on `AttemptAnswer.response`):
  * choice kinds: `{"option_ids": ["<uuid>", ...]}` (bare list/id also accepted);
  * numeric: `{"value": "3.14"}` (bare number/string also accepted).
* `grade_choice(kind, correct_ids, response, option_misconceptions)`:
  * MCQ_SINGLE / TRUE_FALSE: correct iff exactly the correct option is selected;
  * MCQ_MULTI: `is_correct` iff selected == correct; partial score
    `(matched - wrong) / correct`, clamped 0..1;
  * returns the misconception ids hit by wrong options.
* `grade_numeric(key, response)`: exact when no tolerance; otherwise accepted if
  within `tolerance_abs` **or** within `tolerance_rel * |correct|`.
* `grade(kind, ...)` dispatches by kind string.

## 3. Deterministic selection

`services.select_question_ids(quiz, seed)`:

1. PUBLISHED questions in the quiz scope — `topic` (most specific) → `chapter`
   → `subject` — filtered by `difficulty_range`;
2. stable ordering by `uuid`, then `random.Random(seed).shuffle`;
3. first `num_questions`.

`QuizAttempt.question_ids` stores the resolved ordered list so an attempt is
reproducible even if the question pool later changes.

## 4. Endpoints

| Method | Path | Who | Behaviour |
|---|---|---|---|
| POST | `attempts/start/` | student | body `{quiz, seed?}`. Idempotent while an IN_PROGRESS attempt exists (200), else 201. Returns attempt meta + student-safe questions (no explanation, correct flags or numeric key). 400 if no questions match or the quiz is inactive. |
| POST | `attempts/<uuid>/answer/` | student (owner) | body `{question, response, time_spent_s?, hint_used?}`. Server grades; creates/updates `AttemptAnswer` and one `Evidence` row in one transaction. Practice kinds return `is_correct`/`partial_score`/explanation; MOCK_EXAM returns only `{answered: true}`. |
| POST | `attempts/<uuid>/submit/` | student (owner) | computes `score`, sets SUBMITTED, ensures evidence. Idempotent. |
| GET | `attempts/<uuid>/result/` | student (owner) | attempt meta + per-question rows. Feedback is withheld (`feedback_available: false`) for MOCK_EXAM before submit; full after. |
| CRUD | `quizzes/` | teacher author / staff; students read active | teacher-authored quizzes |

Attempts are always scoped to `request.user.student`, so another student's
attempt is a 404. All attempt endpoints require a student profile
(`HasStudentProfile`).

## 5. Evidence

Each graded answer upserts one `Evidence`:

```
source = QUIZ
source_ref_type = "quiz_attempt"
source_ref_id = <attempt uuid>
question = <question>
student/topic/difficulty from the question
score = answer.partial_score (0..1)
occurred_at = grading time
```

Because it is `update_or_create` on the unique key, re-answering and re-submitting
never duplicate evidence — the score is refreshed in place.

## 6. Expiry

`services.expire_if_needed()` marks an IN_PROGRESS attempt EXPIRED once
`started_at + config.time_limit` has passed. It is applied on start/answer/
submit/result. Expiry is persisted **outside** the answer transaction so the
EXPIRED status survives the `AttemptError` that rejects the late answer.

## 7. Tests

* `assessment/tests_grading.py` — pure grading for all kinds (single, multi
  partial/clamped, true/false, numeric abs/rel/both/exact, response extraction,
  dispatcher errors).
* `assessment/tests_attempts.py` — start safety/idempotency/determinism, answer
  grading and revision, misconception capture, question-not-in-attempt, answer
  after submit, evidence exactly once, submit scoring/idempotency, result
  feedback, MOCK_EXAM withholding, permissions, expiry + restart.

`python manage.py test assessment` → 91 tests.
