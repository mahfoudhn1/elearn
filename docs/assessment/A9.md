# Phase A9 — Next.js teacher tools

Status: **implemented.** Teacher authoring tools and class analytics in the
Next.js app, backed by new teacher-scoped analytics endpoints in the `assessment`
Django app. Student-facing behaviour is unchanged.

Companion docs: `docs/assessment/A1.md` (content), `A2.md` (quizzes/attempts),
`A3.md` (mastery), `A4.md` (flashcards), `A8.md` (mobile), `docs/TO_VERIFY.md`.

---

## 1. Privacy model (the core requirement)

A teacher may only see the students they are responsible for:

* students of groups where `Group.admin == teacher`; **or**
* students with a `Subscription(teacher=teacher)`.

`assessment/analytics.py::teacher_students(teacher)` is the single source of
truth for that scope. Class (group) analytics are additionally restricted to
groups the teacher administers: a request for another teacher's group returns
**404** (never 403), so the existence of the group is not revealed.

## 2. Backend — analytics (`assessment/analytics.py`, `teacher_views.py`)

| Endpoint | Scope | Payload |
|---|---|---|
| `GET /api/assessment/teacher/classes/` | own groups | `[{id, name, group_type, student_count}]` |
| `GET /api/assessment/teacher/analytics/` | all own students | `ClassAnalytics` |
| `GET /api/assessment/teacher/classes/<group_id>/analytics/` | one owned group (else 404) | `ClassAnalytics` + `group` |

`ClassAnalytics`:
* `student_count`
* `topic_mastery` — per topic: `subject`, `title_ar/fr`,
  `students_with_evidence`, `avg_mastery` (over trustworthy rows only),
  `distribution` buckets `{no_data, weak, developing, secure, strong}`.
* `most_missed_questions` — per question: `attempts`, `wrong`, `wrong_rate`.
* `common_misconceptions` — per misconception: `code`, `topic`, `count`.
* `students_at_risk` — students whose mean trustworthy mastery is below
  `AT_RISK_THRESHOLD`, with their weakest topics.

All aggregation is standard ORM aggregation; `NONE` confidence counts as
`no_data` and never contributes to an average.

## 3. Backend — teacher import

`StaffQuestionImportView` now allows teachers (`IsTeacherOrStaff`, not staff-only).
A teacher imports **as themselves**; passing another teacher's `author` is
rejected with 403. Staff may still target any teacher. `dry_run` validates and
writes nothing (the report is returned either way).

## 4. Frontend — Next.js (`frontend/elearn/app/dashboard/assessment/`)

* `lib/assessmentApi.ts` — typed client for questions, misconceptions,
  flashcards, import, curriculum, and teacher analytics.
* `layout.tsx` — teacher-only shell (redirects non-teachers to `/dashboard`)
  with tab navigation.
* `page.tsx` — **review queue**: filter by status; submit a DRAFT; publish/reject
  (reviewer actions; server-enforced).
* `questions/new/page.tsx`, `questions/[id]/page.tsx` + `components/QuestionForm.tsx`
  — **question editor**: bilingual prompt/explanation, kind picker, option editor
  with a per-option misconception selector, difficulty, topic picker, and a live
  **LaTeX preview**.
* `components/LatexPreview.tsx` — renders `$...$`/`$$...$$` with KaTeX (loaded
  once via `next/script`), RTL-safe (`dir="auto"`).
* `import/page.tsx` — **import UI** with a JSON editor, a **dry-run** button and
  a per-row report (created/updated/errors with field messages).
* `flashcards/page.tsx` — **flashcard editor**: topic picker, bilingual
  front/back with LaTeX preview, difficulty, plus the submit/publish/reject flow.
* `analytics/page.tsx` — **class analytics**: class selector ("all my students"
  or one group), topic-mastery distribution bars, most-missed questions, common
  misconceptions, students at risk.

## 5. Tests (`assessment/tests_teacher_analytics.py`)

Privacy:
* a teacher's class list contains only their own groups;
* a class's analytics are scoped, and another teacher's group is 404;
* the overview never includes another teacher's students;
* only teachers may call the analytics endpoints (student → 403, anon → 401).

Aggregation:
* topic-mastery distribution buckets and average; `NONE` → `no_data`;
* most-missed questions (wrong rate);
* common misconceptions (count);
* students-at-risk selection and weakest-topic list;
* teacher B's students never appear in teacher A's aggregates.

Import:
* a teacher can dry-run import as themselves (writes nothing);
* a teacher cannot import as another teacher (403);
* a student cannot import (403).

14 tests, all green.
